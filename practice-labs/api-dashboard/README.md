# Practice Lab 2: API Explorer Dashboard

## Learning Focus
- `useEffect` for side-effect data fetching
- Managing asynchronous lifecycle states: loading, success, and error
- Graceful fallbacks and defensive network programming
- Derived state calculations (filtering users in-memory during render)
- Modal dialogs and detail inspection

## Features
- Fetches remote user records on component mount.
- Real-time client-side search filtering across names and emails.
- Interactive user cards with click-to-view detail modal.
- Resilient fallback dataset if network request is interrupted.

## How to Run
```bash
cd practice-labs/api-dashboard
npm install
npm run dev
```
