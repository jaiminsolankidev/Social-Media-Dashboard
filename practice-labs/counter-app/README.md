# Practice Lab 1: Interactive Counter & Task Manager

## Learning Focus
- React functional components
- Component props
- State management with `useState`
- Event handling in JSX
- List rendering with stable `key` props
- Conditional rendering (completed styles & symbols)

## Features
- **Counter:** Increment, decrement with zero floor, and reset.
- **Task Manager:** Create tasks, toggle completion status, and remove tasks.
- **Pure Local State:** Demonstrates isolated component state transitions with functional updates.

## How to Run
```bash
cd practice-labs/counter-app
npm install
npm run dev
```
