# Practice Lab 3: Mini Social Feed

## Learning Focus
- Reusable component architecture (`PostCard`)
- Passing data down via props and lifting state updates up via callback props
- Complex nested state updates with immutable patterns (`map`, `filter`, spread syntax)
- Form control and validation in social feed contexts

## Features
- Interactive feed with like / unlike toggle and live counter updates.
- Real-time comment submission per post.
- Post creator for publishing new image updates with custom captions.
- Demonstrates component modularity and clean unidirectional data flow.

## How to Run
```bash
cd practice-labs/mini-social-feed
npm install
npm run dev
```
